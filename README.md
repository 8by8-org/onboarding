# Onboarding

Welcome to 8by8! We are thrilled to have you on our team.

This repository contains exercises designed to help you get comfortable with the
recommended workflow for contributing to 8by8 projects.

## Topics Covered

- Our recommended Git workflow
- Configuring your environment
- TypeScript essentials
- Unit testing with Vitest
- Linting and formatting your code
- Writing TSDoc comments
- CI/CD pipeline basics
- Code style
- Authoring Wiki pages

## Getting Started

Work through the wiki pages in this order:

1. Read the prerequisites: [Git](wiki/prerequisites/git.md), [Node.js](wiki/prerequisites/node-js.md), and [VSCode](wiki/prerequisites/vscode.md).
2. Follow the getting-started guides: [01 - Forking the Repo](wiki/getting-started/01-forking-the-repo.md), [02 - Project Overview](wiki/getting-started/02-project-overview.md), and [03 - Project Setup](wiki/getting-started/03-project-setup.md).
3. Complete the exercises in order: [01 - Algorithms and Testing](wiki/exercises/01-algorithms-and-testing.md), [02 - Writing TSDoc Comments](wiki/exercises/02-writing-tsdoc-comments.md), [03 - Fixing Type Errors](wiki/exercises/03-fixing-type-errors.md), [04 - Fixing Linting Issues](wiki/exercises/04-fixing-linting-issues.md), and [05 - Fixing Formatting](wiki/exercises/05-fixing-formatting.md).
