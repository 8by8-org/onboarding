# Onboarding

Welcome to 8by8! We are thrilled to have you on our team.

This repository contains exercises designed to help you get comfortable with the
recommended workflow for contributing to 8by8 projects.

## Topics Covered

- Our recommended Git workflow
- TypeScript essentials
- Unit testing with Vitest
- Linting and formatting your code
- Writing TSDoc comments
- CI/CD pipeline basics
- Opening pull requests and working with required checks
- Syncing your fork after changes are merged

## Getting Started

Work through the docs pages in this order:

1. Read the prerequisites: [Git](docs/prerequisites/git.md), [Node.js](docs/prerequisites/node-js.md), and [VSCode](docs/prerequisites/vscode.md).
2. Follow the getting-started guides: [01 - Forking the Repo](docs/getting-started/01-forking-the-repo.md), [02 - Project Overview](docs/getting-started/02-project-overview.md), and [03 - Project Setup](docs/getting-started/03-project-setup.md).
3. Complete the exercises in order: [01 - Algorithms and Testing](docs/exercises/01-algorithms-and-testing.md), [02 - Writing TSDoc Comments](docs/exercises/02-writing-tsdoc-comments.md), [03 - Fixing Type Errors](docs/exercises/03-fixing-type-errors.md), [04 - Fixing Linting Issues](docs/exercises/04-fixing-linting-issues.md), and [05 - Fixing Formatting](docs/exercises/05-fixing-formatting.md).
4. Finish the workflow with [01 - Making a PR](docs/wrapping-up/01-making-a-pr.md) and [02 - Syncing Your Fork](docs/wrapping-up/02-syncing-your-fork.md).
