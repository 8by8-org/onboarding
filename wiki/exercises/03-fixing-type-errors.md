# 03 - Fixing Type Errors

This exercise lives in `src/onboarding/<your-github-username>/03-type-errors.ts`.

## Goal

Fix the TypeScript errors in the file without changing the intended behavior.

## Relevant Scripts

- `npm run typecheck`

## What To Do

1. Open the file in VSCode.
2. Notice that the IDE highlights type errors and marks files that contain them.
3. Fix the incorrect types until the file is valid TypeScript.
4. Run `npm run typecheck` to confirm the errors are resolved.

## Done Looks Like

- VSCode no longer shows type errors in the file.
- `npm run typecheck` passes for your changes.
