# VSCode

We recommend using VSCode for onboarding because it makes the exercise workflow
easier to see. The editor will surface TypeScript problems, test files, and
formatting tools in one place.

## Install VSCode

1. Download VSCode from [code.visualstudio.com](https://code.visualstudio.com/).
2. During installation, enable the `code` command in your PATH if the installer
   offers that option.
3. Open a new terminal and verify the command works:

```
code .
```

## Recommended Extensions

- Prettier
- ESLint

The formatting exercise guide also describes using format on save with the
Prettier extension.
