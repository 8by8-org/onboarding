# Node.js

Node.js is required to install dependencies and run the scripts in this repo.

## Install Node.js

1. Download the current LTS release from [nodejs.org](https://nodejs.org/).
2. Install Node.js, which also installs npm.
3. Open a new terminal and verify both commands are available:

```
node --version
npm --version
```

## What You Will Use It For Here

- `npm install` to install dependencies
- `npm run onboard <your-github-username>` to generate your exercises
- `npm run test`, `npm run lint`, `npm run typecheck`, and `npm run format`
