# Git

Git is required for cloning the repository, creating a feature branch, and
pushing your onboarding work back to your fork.

## Install Git

1. Download Git from [git-scm.com](https://git-scm.com/downloads).
2. Install it with the default options unless you already have a preferred Git
   setup.
3. Open a new terminal and verify the installation:

```
git --version
```

## Configure Your Identity

If you have not configured Git on this machine yet, set your name and email:

```
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

## What You Will Use It For Here

- Forking this repository on GitHub
- Cloning your fork locally
- Creating an onboarding branch
- Committing your exercise solutions
