# 04 - Fixing Linting Issues

This exercise lives in `src/onboarding/<your-github-username>/04-lint.ts`.

## Goal

Resolve the lint problems in the file without changing the intended behavior.

## Relevant Scripts

- `npm run lint`

## What To Do

1. Remove unused values.
2. Replace unsafe uses of `any` with concrete types.
3. Keep the function behavior the same.
4. Run `npm run lint` until the file is clean.

## Done Looks Like

- The file no longer has the targeted lint issues.
- `npm run lint` passes for your changes.
